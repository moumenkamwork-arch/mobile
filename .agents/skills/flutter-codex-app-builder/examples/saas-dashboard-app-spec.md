# Example App Spec: SaaS Dashboard

## Product idea

A cross-platform dashboard for teams to monitor metrics, tasks, and account settings.

## MVP features

- Auth and workspace selection.
- Dashboard overview.
- Charts and filters.
- Task/detail management.
- Team members and roles.
- Settings and billing placeholder.

## Architecture notes

- Use responsive/adaptive layouts for mobile/tablet/web.
- Define chart recommendations through the design system.
- Keep analytics/business metrics contracts typed.
- Browser E2E tests are important for web/admin usage.

## Launch notes

- Prepare web smoke tests.
- Prepare accessibility keyboard/focus QA.
- Prepare privacy matrix for team/member data.
