# Store Screenshot Workflow

Use this guide for Google Play and App Store screenshot planning.

## Goals

- Show real app value, not generic device mockups.
- Match current UI and product claims.
- Cover the primary user journey.
- Localize captions and screens for supported markets.

## Shot plan

1. Value proposition screen.
2. Primary workflow screen.
3. Differentiating feature screen.
4. Trust/safety/privacy screen when relevant.
5. Subscription/premium screen when relevant.
6. AI feature screen when relevant.
7. Settings/profile or management screen when relevant.

## Caption rules

- Use concise benefit-driven copy.
- Do not claim unavailable features.
- Avoid misleading rankings, guarantees, medical/legal/financial claims unless substantiated.
- Keep captions short enough for small devices.
- Prepare localized variants for each store locale.

## QA checklist

- Screenshots match the submitted build.
- No test data, secrets, tokens, private emails, or real PII.
- Status bars are clean.
- Dark/light variants are intentional.
- Tablet/iPad screenshots exist when required or beneficial.
